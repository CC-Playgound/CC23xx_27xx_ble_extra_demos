# CS_CM_embedded demo 纯享版

## 简介

本工程是一个简化版的 Channel Sounding + Connection Monitor（CS/CM）嵌入式 demo。相较于 UART 版本，这里重点保留 CS/CM 的核心功能流程，去掉了部分不必要的外部控制与调试链路，例如外部控制模块、NPI 相关辅助路径等，使其更适合做“纯净版”功能验证和代码阅读。

## 适用场景

- 需要在 CC2745R10 平台上快速验证 Channel Sounding 的基本运行逻辑
- 需要验证 Connection Monitor 的连接状态处理与相关输出
- 适合用于功能初步验证、调试观察和代码理解

## 硬件要求

- 2 块 CC2745R10 / CC2745R10-Q1 LaunchPad（推荐）
  - 1 块作为 Car Node
  - 1 块作为 Key Node / 另一端设备
- USB 调试连接线
- 视实际测试情况，可能还需要标准的电源和连接线

## 软件环境

- Code Composer Studio（CCS）
- SimpleLink Low Power F3 SDK 9.20.01.21 或更高版本
- 与当前工程对应的 TI 编译工具链与 SDK 版本

## 工程说明

当前目录下提供的是一个简化后的嵌入式工程，重点是保留 CS/CM 的核心逻辑实现，避免额外的外部控制模块干扰。与 UART 版相比，本版本更关注：

- 代码结构更清晰
- 依赖更少
- 更容易快速上手和进行基础调试

## 使用步骤

1. 打开 CCS，并导入当前工程目录下的项目。
2. 确认工程使用的 SDK 版本与本机环境一致。
3. 编译并烧录到对应的 CC2745 LaunchPad。
4. 按照 CS/CM 的正常连接方式完成两端设备的配对与连接。
5. 通过串口、日志或调试输出观察 Channel Sounding 与 Connection Monitor 的运行结果。
6. 如需进一步调整参数，可在工程配置或代码中修改相关宏定义和配置项。

## 与 UART 版的区别

- 保留核心 CS/CM 功能
- 去掉了不必要的外部控制相关入口
- 减少了额外的辅助组件和调试链路
- 更适合做“最小可用版本”的功能验证

## 注意事项

- 建议先确认 SDK 版本与项目配置一致，避免编译或烧录问题。
- 如果观察到连接异常，优先检查两端设备的连接关系、调试端口和供电情况。
- 如果你需要进一步扩展为更完整的演示版本，可以参考 UART 版的思路，在此基础上补充串口输出、日志格式化或更丰富的交互逻辑。
